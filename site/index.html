ICAO 콜사인, IATA 환산 편명 또는 항공사 코드로 검색합니다. 예: KAL81, KE81, KAL. 앞자리 0 및 공백은 자동 정리합니다. 같은 검색창에서 공항의 IATA/ICAO 코드, 영문 공항명·도시명 또는 주요 공항의 한글 명칭을 입력할 수 있습니다. 공항을 선택하면 등록 노선을 출발·도착·전체(경유 포함)로 조회합니다. 출발은 해당 공항이 구간 시작점, 도착은 구간 끝점인 경우이며 경유 공항은 양쪽에 나타날 수 있습니다. 실제 운항 시간표가 아닙니다. Airport local time은 기기 시각 기준 현재 공항 현지 날짜·시각입니다. 예정 출발·도착 시각(STD/STA)이 아닙니다. IANA 시간대와 기기의 시간대 규칙으로 서머타임을 반영하며, 규칙이 최신이 아니거나 시간대 정보가 없으면 정확성을 보장할 수 없습니다. 휴대폰에서 입력 중에는 검색창과 결과를 위쪽에 압축해 표시합니다. 키보드의 검색 버튼이나 검색창 옆 완료 버튼을 누르면 키보드가 닫히고 전체 화면으로 돌아갑니다. 여러 노선은 스크롤하여 확인하세요. IATA 환산값은 실제 판매 편명과 다를 수 있습니다.

온라인에서 최초 DB를 저장한 뒤 홈 화면에 추가한 앱을 실행하여 오프라인 준비 상태를 확인하세요. 앱 실행 또는 재활성화 시 약 5일(5일~5일 12시간)마다 작은 DB 버전 정보만 확인하고, 노선 데이터가 실제로 변경된 경우에만 전체 DB를 다운로드합니다. DB 업데이트 버튼은 즉시 확인합니다. 백업은 선택 사항이며 업데이트만으로 기기에 저장됩니다. iOS 저장소가 삭제될 수 있으므로 출발 전 비행기 모드에서 앱을 완전히 종료한 뒤 다시 열어 확인하세요.

출처: Virtual Radar Server standing-data (CC0). 공항 시간대: airportsdata (MIT) · 라이선스. 노선은 등록된 참고 정보이며 실시간 운항, 목적지 변경, 결항, 날짜별 스케줄 또는 실제 판매 편명을 보장하지 않습니다. 운항 판단용이 아닙니다.

등록된 참고 노선이며 실제 운항·회항·목적지는 확인할 수 없습니다. 운항 판단에 사용하지 마시고 소속 회사의 전자기기 사용 규정을 준수하세요.
