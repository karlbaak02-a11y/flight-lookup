ICAO 콜사인, IATA 환산 편명 또는 항공사 코드로 검색합니다. 예: KAL81, KE81, KAL. 앞자리 0 및 공백은 자동 정리합니다. IATA 환산값은 실제 판매 편명과 다를 수 있습니다.

온라인에서 최초 DB를 저장한 뒤 홈 화면에 추가한 앱을 실행하여 오프라인 준비 상태를 확인하세요. 앱 실행 시 마지막 확인 후 24시간이 지나면 자동 갱신을 시도합니다. iOS 저장소가 삭제될 수 있으므로 출발 전 비행기 모드에서 앱을 완전히 종료한 뒤 다시 열어 확인하세요.

출처: Virtual Radar Server standing-data (CC0). 노선은 등록된 참고 정보이며 실시간 운항, 목적지 변경, 결항, 날짜별 스케줄 또는 실제 판매 편명을 보장하지 않습니다. 운항 판단용이 아닙니다.
